# Pokemon Explorer

A modern, interactive web application built with React that allows users to explore and discover information about various Pokemon. The application fetches data from the PokeAPI and presents it in an engaging, user-friendly interface.

## Live Demo

Check out the live version of the application: [Pokemon Explorer](https://pokemon003.netlify.app/home)
or  [Pokemon Explorer](https://pokemon.murshed.io/home)

## Features

- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Interactive UI**: Smooth animations and transitions for an engaging user experience
- **Pokemon List**: Browse through a collection of Pokemon with their basic information
- **Detailed View**: Click on any Pokemon to see detailed information including stats, abilities, and more
- **Search Functionality**: Easily find your favorite Pokemon using the search feature
- **Modern Styling**: Clean and modern UI with smooth animations and transitions

## Technologies Used

- React.js
- React Router for navigation
- CSS3 for styling with modern features like Flexbox and CSS Grid
- PokeAPI for Pokemon data
- Vite for fast development and building

## Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mrshed21/Pokemon2.git
   cd Pokemon2
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and navigate to `http://localhost:5173`
